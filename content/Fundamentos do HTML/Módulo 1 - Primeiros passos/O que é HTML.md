# O que é HTML

> [!abstract] Ideia central
> HTML (**HyperText Markup Language**) é uma linguagem de **marcação**, não de programação: não tem lógica (condicionais, loops), só estrutura conteúdo através de **tags**. O "hiper" vem de hipertexto — texto que carrega links para outros conteúdos.

---

## O que é uma linguagem de marcação

HTML fica no universo da programação, tem sintaxe e regras próprias de escrita, mas **não é uma linguagem de programação** — não existem estruturas como `if`, `for` ou funções. O que existe são **tags**, que marcam pedaços do conteúdo para dizer o que cada um significa.

| Termo | O que é |
|---|---|
| Tag | A marcação em si (ex: `<a>`) — pode ter texto, atributos, e sempre gera algo na página |
| Elemento | Uma tag completa (abertura + conteúdo + fechamento) |
| Hypertext | Texto "poderoso": carrega links para outros textos/páginas, além de imagens, áudio e vídeo |

## Por que "hipertexto"

Antes da internet, textos em livros e jornais eram estáticos — no máximo tinham imagens. Com a internet, o texto ganhou **links**: um clique leva a outro lugar. É isso que torna o HTML um hipertexto, e com o tempo esse "texto" passou a carregar imagens, áudio, vídeo e muito mais.

```html
<a href="https://rocketseat.com.br">Ir para outra página</a>
```

Esse `<a>` é a marcação de link — o clique nesse texto leva a pessoa para outra página, exatamente o conceito de hipertexto.

## Extensão de arquivo

Arquivos escritos em HTML usam a extensão **`.html`** (ex: `index.html`).
