# Comentários no HTML

> [!abstract] Ideia central
> Comentários (`<!-- -->`) são texto que o navegador **ignora** ao renderizar a página. Servem para documentar decisões, deixar lembretes ou "desligar" um trecho de código temporariamente.

---

## Sintaxe

```html
<!-- Isso é um comentário e não aparece na página -->
<p>Este texto aparece normalmente.</p>
```

- Abre com `<!--` e fecha com `-->`
- Tudo entre esses sinais é ignorado na renderização — não importa o que tenha dentro
- Pode ter várias linhas:

```html
<!--
  TODO: trocar essa imagem pela versão final
  antes de publicar
-->
```

## Para que serve

- Documentar o porquê de uma escolha no código
- Deixar anotações e lembretes para você mesmo ou para o time
- Organizar visualmente seções grandes de HTML
- "Comentar" (desativar) um trecho temporariamente, sem apagar o código

---

## Pontos-chave

- [ ] Sintaxe: `<!-- conteúdo -->`
- [ ] O que está dentro do comentário **não aparece** na página renderizada
- [ ] Funciona em uma ou várias linhas
- [ ] Útil para documentar e organizar o código
