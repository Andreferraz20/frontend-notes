# Fundamentos do HTML

> [!abstract] Índice geral
> Parte do curso [[Front-end]] dedicada aos fundamentos de HTML: da definição da linguagem até a estruturação completa de uma página com tags semânticas.

---

## Módulos

| # | Módulo | O que cobre |
|---|---|---|
| 1 | [[Módulo 1 - Primeiros passos]] | O que é HTML, comentários, anatomia de tags, fluxo, aninhamento, caracteres reservados |
| 2 | [[Módulo 2 - Atributos]] | Sintaxe de atributos, booleanos, globais (`id`, `class`, `data-*`, `style`) |
| 3 | [[Módulo 3 - Elementos de conteúdos]] | Semântica, títulos/parágrafos, formatação de texto, listas, código, links, imagens |
| 4 | [[Módulo 4 - Elementos Estruturais]] | Esqueleto do documento e tags estruturais (`header`, `main`, `nav`, `section`, `article`, `aside`, `footer`, `div`, `span`) |

---

## A progressão do curso

```
1. Entender o que é HTML e a anatomia de uma tag
        ↓
2. Configurar tags com atributos
        ↓
3. Dar significado ao conteúdo (semântica)
        ↓
4. Estruturar a página inteira
```
