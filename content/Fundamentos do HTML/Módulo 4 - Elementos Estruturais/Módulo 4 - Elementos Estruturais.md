# Módulo 4 - Elementos Estruturais

> [!abstract] O que este módulo cobre
> Como montar o esqueleto de um documento HTML e organizar o layout de uma página com tags semânticas estruturais: `header`, `main`, `aside`, `footer`, `nav`, `section`, `article` — e as genéricas `div`/`span` para quando nenhuma tag semântica se encaixa.

## Layout típico de uma página

```
<html>
├── head (configuração, invisível)
└── body
    ├── header
    │   └── nav
    ├── main
    │   └── article / section
    ├── aside
    └── footer
```
